# Design notes

Short specs written before a feature was built, each saying what the
feature is, why it is that shape and what was decided against. They are a
selection: the ones about the product itself. Others were written about
the hosted service, its plans and its operations, and are not published,
so a note here sometimes names one ("the glass spec") that you will not
find beside it.

They describe what was decided at the time, and the code is the final word
where the two differ. For how the parts fit together, start with
[the architecture](../architecture.md); for the API, [the contract](../api.md).
